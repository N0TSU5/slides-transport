# From Gridlock to Green Lanes

A 3-slide animated web presentation on inefficiencies in transport & delivery, and how
route optimisation, demand prediction and generative AI fix them.

Single static file (`index.html`), no build step.

## Present
- Open `index.html` in a browser (works offline except Google Fonts).
- `←` / `→` (or space, swipe) to move between slides · `H` hides slides to show the roads · `F` fullscreen.
- Link straight to a slide with `#1`, `#2`, `#3`.

## Publish on GitHub Pages
1. Push this folder to a GitHub repo.
2. Repo **Settings → Pages → Build and deployment → Deploy from a branch**, pick `main` / `/ (root)`.
3. Your deck is live at `https://<user>.github.io/<repo>/`.
